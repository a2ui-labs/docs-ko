# A2UI in the World

A2UI는 Google 내부 팀과 파트너 조직에서 차세대 에이전트 주도 애플리케이션을 만들기 위해 채택되고 있습니다. 아래는 실제 사용 사례입니다.

## 프로덕션 배포

### Google Opal: 모두를 위한 AI 미니 앱

[Opal](http://opal.google)은 수십만 명의 사용자가 코딩 없이 자연어로 AI 미니 앱을 만들고, 수정하고, 공유할 수 있게 합니다.

A2UI는 Opal의 동적 생성형 UI 시스템을 구동하는 핵심 기반입니다.

### Gemini Enterprise: 비즈니스를 위한 커스텀 에이전트

Gemini Enterprise는 기업이 특정 워크플로와 데이터에 맞춘 강력한 커스텀 AI 에이전트를 만들 수 있게 해 줍니다. A2UI는 에이전트가 비즈니스 애플리케이션 안에서 풍부하고 상호작용적인 UI를 렌더링하도록 통합되고 있습니다.

### Flutter GenUI SDK: 모바일을 위한 생성형 UI

[Flutter GenUI SDK](https://docs.flutter.dev/ai/genui)는 모바일, 데스크톱, 웹 전반의 Flutter 애플리케이션에 동적인 AI 생성 UI를 제공합니다. GenUI는 서버 측 에이전트와 Flutter 앱 간 통신의 기반 프로토콜로 A2UI를 사용합니다.

### Google ADK: Agent Development Kit

[Agent Development Kit](https://google.github.io/adk-docs/)는 AI 에이전트를 만들고 배포하기 위한 Google의 오픈 소스 프레임워크입니다. 내장 개발자 UI인 [ADK Web](https://github.com/google/adk-web)은 네이티브 A2UI 렌더링을 포함합니다.

## 파트너 통합

### AG UI / CopilotKit

[AG UI](https://ag-ui.com/)와 [CopilotKit](https://www.copilotkit.ai/)은 **A2UI와 즉시 호환되는** 에이전트 애플리케이션용 프레임워크를 제공합니다.

### Google의 AI 기반 제품

Google이 전사적으로 AI를 도입함에 따라 A2UI는 에이전트가 텍스트뿐 아니라 **사용자 인터페이스 자체를 교환할 수 있는 표준화된 방법**을 제공합니다.

## 커뮤니티 프로젝트

### 오픈 소스 예제

- **Restaurant Finder** - 동적 폼을 포함한 테이블 예약 데모
- **Contact Lookup** - 결과 목록이 있는 검색 UI
- **Component Gallery** - 모든 컴포넌트를 살펴볼 수 있는 인터랙티브 쇼케이스

### 서드파티 통합

- **json-render** - A2UI 컴포넌트 카탈로그 렌더링용 React 라이브러리
- **OpenClaw Canvas** - 캔버스 시스템을 통해 에이전트 생성 UI를 렌더링하는 예시
