# 커뮤니티

A2UI 커뮤니티에 오신 것을 환영합니다. 우리는 에이전트 주도 인터페이스의 미래를 함께 만들고 있습니다.

## 참여하기

A2UI는 Apache 2.0 라이선스를 따르는 오픈 소스 프로젝트입니다. 개발자, 연구자, 그리고 agentic UI 발전에 관심 있는 누구나 기여할 수 있습니다.

## 커뮤니티 쇼케이스

직접 A2UI로 무엇인가를 만들었다면, GitHub Discussions에 짧은 설명, 코드 링크, 4분 이내의 데모 영상을 함께 올려 주세요. 눈에 띄는 프로젝트는 문서와 릴리스 노트에서 소개할 수 있습니다.

## 프로젝트 파트너

A2UI는 Google Opal, Flutter(GenUI SDK), Gemini Enterprise, AG UI / CopilotKit, A2A 팀과 협력하며 개발되고 있습니다. 자세한 사례는 [A2UI in the World](a2ui-in-the-world.md)를 참고하세요.

## 행동 강령

우리는 모두에게 환영받고 포용적인 환경을 제공하기 위해 노력합니다.

- 서로 존중하고 배려하기
- 새로운 사람을 환영하고 시작을 돕기
- 커뮤니티에 가장 도움이 되는 것에 집중하기
- 타인에게 공감하기

용납할 수 없는 행동은 허용하지 않습니다. 우려 사항은 프로젝트 유지 관리자에게 알려 주세요.

## 기여 인정

모든 기여에 감사드립니다. 기여자는 다음 항목에서 인정받습니다.

- GitHub 기여자 그래프
- 릴리스 노트
- 프로젝트 감사의 글

중대한 기여자는 유지 관리자 팀에 초대될 수 있습니다.
